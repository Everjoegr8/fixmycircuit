# Open boards shipped with FixMyCircuit

Real, openly licensed boards that the app installs on first launch so a new
user can see a full-size board (real pads, real copper, real nets) straight
away. Each model folder has a `model.json` (brand, series, model, source,
licence) and the upstream `LICENSE.txt`. Only open-hardware designs whose
licence allows redistribution belong here, never phone makers' boards.
